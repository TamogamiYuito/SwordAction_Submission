# VR Sword Action

## 作品概要

Unreal Engine 5を使用して制作したVRソードアクションゲームです。

VRコントローラーを使用して剣を掴み、
実際に手を動かして剣を振ることで敵を攻撃できます。

Unreal Engine 5のVR機能を利用し、
VRコントローラーの入力処理、武器の把持、攻撃、スキルなどの
ゲーム側の処理をC++で実装しました。

## 開発環境

- Unreal Engine 5
- C++
- OpenXR
- VRヘッドセット

## 主な実装

### VRコントローラー入力

VRコントローラーからの入力を取得し、
プレイヤーの手の操作としてゲーム内へ反映する処理を実装しました。

Unreal Engine 5のVR機能を利用しながら、
ゲーム側の入力処理をC++で構築しています。

### 武器の把持処理

VRコントローラーを使用して、
ゲーム内の剣を掴んで操作できる仕組みを実装しました。

プレイヤーが実際にコントローラーを動かすことで、
ゲーム内の剣も連動して動くようにしています。

### 剣による攻撃処理

プレイヤーがVRコントローラーを動かして剣を振り、
敵へ攻撃できる処理を実装しました。

単純なボタン操作ではなく、
VRならではの身体動作をゲーム内の攻撃へ反映しています。

### スキル処理

通常攻撃だけでなく、
特定の入力によって発動するスキル処理も実装しました。

通常の剣による攻撃とは異なるアクションを追加することで、
戦闘の幅を広げることを意識しました。

## 自身の担当・実装

- Unreal Engine 5を使用したVRゲームシステムの制作
- C++によるVRコントローラー入力処理
- C++による武器の把持処理
- 剣を使用した攻撃処理
- スキル処理
- VR空間でのプレイヤー操作の調整

## 工夫した点

本作品では、
一般的なゲームパッドによるボタン操作ではなく、
プレイヤー自身がコントローラーを動かすVR特有の操作を
ゲームシステムへ反映することを重視しました。

特に剣の操作では、
プレイヤーの手の動きとゲーム内の武器を連動させることで、
実際に武器を扱っているように感じられる操作を目指しました。

また、Blueprintだけに依存せず、
VRコントローラー入力や武器の操作などの主要なゲーム処理を
C++で実装することにも取り組みました。

## 外部アセットについて

本作品では、
第三者が制作した3Dモデルやその他の外部アセットを使用しています。

ライセンス上の理由から、
本リポジトリには外部アセットのデータを含めず、
自身で実装したC++ソースコードを中心に掲載しています。

そのため、
本リポジトリ単体では完成したゲームをそのまま実行することはできません。
